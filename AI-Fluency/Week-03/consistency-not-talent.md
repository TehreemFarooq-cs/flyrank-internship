# Portfolio Visual Identity & Asset Governance: DoseForecast Tracker

## 1. Visual Identity Principles
* **Color Palette:** Monochromatic dark mode foundation (Slate-950 background, Slate-900 surface cards) paired with a high-contrast Medical Teal accent (Emerald-400/Teal-400) for active inventory states and critical alerts.
* **Typography:** Inter or system sans-serif stack. Clean hierarchy with strict font weights (Font-bold for metric readouts, Font-normal for body descriptions) to maintain readability across data-dense views.
* **Layout & Spacing:** Generous whitespace anchored by 8pt grid spacing (`p-4`, `gap-6`), rounded container cards (`rounded-xl border border-slate-800`) and subtle drop shadows to separate form elements from background dashboards.

## 2. Frame, Not Upstage Rule
* **The Rule:** The portfolio's visual design must act as a neutral gallery frame that directs recruiter attention entirely to the technical case studies, code architecture and live data outputs. 
* **Application:** Avoid flashy decorative backgrounds, complex CSS animations, or saturated color gradients. The UI should remain understated so that the functional proof—such as the medication inventory table and refill forecast charts—stands out immediately.

## 3. Asset & Image Governance
* **Real Screenshots Over AI Generation:** Prioritize actual UI captures of the working React application, component trees and terminal execution logs for functional proof.
* **AI Image Discipline:** Restrict AI-generated assets strictly to abstract architectural diagrams or placeholder icon assets. Reject any decorative, overly complex, or photorealistic AI art that distracts from core engineering competency.

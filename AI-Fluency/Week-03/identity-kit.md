# Portfolio Identity Kit: Decide Once

## 1. Typography
* **Heading Font:** Inter (Bold / Semi-bold)
* **Body Font:** Inter (Regular / Medium)

## 2. Color Palette
* **Background (Near-White):** `#F8FAFC` (Slate-50)
* **Text (Near-Black):** `#0F172A` (Slate-900)
* **Main Surface / Cards:** `#FFFFFF` (Pure White / Slate-100 borders)
* **Accent (Calm / Controlled):** `#0D9488` (Medical Teal / Teal-600)

## 3. Logo & Favicon
* **Format:** Clean text monogram (`AF` set in Inter Bold) or full name set in Inter font with a subtle teal accent dot.

## 4. Two-Line Style Note
* **Fonts:** Inter for both headings and body to ensure sharp readability. 
* **Palette & Mood:** Monochromatic light foundation anchored by a calm medical teal accent, creating a minimal, clinical and data-dense aesthetic that frames the technical work without competing with it.
